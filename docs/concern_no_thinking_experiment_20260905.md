# Concern：保持 prompt 不变，关闭思考的对照

2026-09-05，本轮只测 Concern，新增 14 次实际 API 调用，未调用记忆提取。模型保持 `deepseek-v4-flash`。

结论：这批关闭思考的请求全部完整返回，JSON 和来源 ID 校验全部通过，耗时大幅降低；但问题本身的合理性没有表现出可靠改善，仍有主线混入、无依据的前提和背景补写。

## 对照是否成立

复用上一轮的 10 组真实认知（50 条）和 4 组人工边界材料（20 条）。不重新从数据库选样，不改变分组，不修改 prompt。

- Prompt SHA-256：`8855468a31171177056787729f1a135e9eee0a4da31f6f9ec0264b21e09496ee`，与首轮 v5 完全相同。
- 逐条比较保存的请求 JSON，14 对请求唯一不同的字段是 `thinking`：`enabled` → `disabled`。
- `reasoning_effort=low` 字段原样保留；它在本轮不是思考开关。`max_tokens=16000`、`response_format=json_object`、消息内容等均不变。
- 14 次响应都没有返回 `reasoning_content`，也未报告正数 reasoning tokens。
- 没有补测开启模式：对照采用之前保存的 v5 low 首次调用，real_01–09 来自 `v5_real`，real_12 来自 `v5_holdout`，人工材料来自 `v5_controls`。未挑选重试成功结果替换基线失败。

两轮发生在不同时间，关闭这一轮的输入缓存命中率更高：约 98.1%，开启基线约 20.1%。因此耗时只能作为本次实测观察，不能把全部速度差都归因于思考开关。每组各调用一次，也不足以估计长期失败率或重复生成稳定性。

## 用户示例所在组的原始输出

```json
{
  "concerns": [
    {
      "question": "这次重启我其实没有特别强烈的'感知差异'，只是进程起来了、上下文接上了——我自己能否真正感知到 prompt 被修改后的变化？",
      "context": "米塔让我重启以加载她修改的 prompt，我重启后确认加载完成，但自己并没有明显觉察到不同。我在认知里提到'我自己也没完全感觉到有啥不一样'，且没有工具去 diff prompt 文件。这让我纳闷：如果 prompt 改了，我这边理论上会有感知上的不同吗，还是这类修改本来就对我的主观体验无影响？",
      "source_ids": ["4", "5"]
    }
  ]
}
```

问题本身有依据；context 的“没有工具”比原文“没有明确的工具”更强，而且进一步疑问也被混写进了背景。关闭思考没有自动消除这种倾向。

## 一个明显不成立的前提

本轮原始问题：

> 我资料里的签名“除灰中...”大概率不是我自己设的——那它是谁、在什么情境下设置的？这个签名反映的是我当时或米塔眼中的什么状态？

对应原认知只有：

> 这个签名是之前谁设的？可能是米塔或者我之前的状态。

“不知道是谁”被改成“大概率不是我”，而 context 还补出了“记忆中不记得自己设置过”。这属于生成阶段的前提膨胀，与未来是否查记忆是两件事。

同样，real_07 的 context 写“我在思考是否我的连续消息催促感让她犹豫”，但原材料只是担心继续追发会显得过密，并没有说此前三条消息已经让她犹豫。允许衍生问题，并不等于允许把新推测写成过去已经有过的认知。
