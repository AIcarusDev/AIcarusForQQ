# QQ 好友管理

Bot 可以在 `qq_contacts` 中自主使用以下工具，无需 Guardian 审批：

- `list_friend_requests`：查询当前 QQ 账号收到且尚未处理的申请。
- `handle_friend_request`：按申请 `flag` 接受或拒绝；接受时可设置备注。
- `delete_friend`：按 QQ 号解除好友关系，保留本地聊天记录。

适配器使用 OneBot `request/friend` 事件，以及 `set_friend_add_request` 和
`delete_friend` 接口。写操作检查完整响应的 `status` 和 `retcode`，支持成功时
`data=null` 的返回；失败或超时不会报告成功。

申请保存在 `qq_friend_requests` 表，按 Bot 账号与申请标识去重。重启后恢复待处理
申请；已处理申请不会被重复推送重新激活。同一服务串行执行好友管理写操作。
收到新申请会唤醒 Bot，QQ 页面显示待处理申请；QQ 未打开时显示跨平台注意事件。

此列表来源于本程序收到的事件，不是 QQ 服务端历史申请列表。升级前被忽略、离线
期间未补发的申请不会凭空恢复，需要申请人重新发送。通过 QQ 客户端在外部处理或
已过期的申请仍可能留在本地列表中，以适配器审批结果为准。

临时会话若缺少来源群，从该用户所在群打开私聊时会校验群成员身份、补齐来源，
并保存到内存和数据库。无法查询好友关系、没有来源群或成员校验失败时返回明确
错误。好友审批不修改会话白名单设置。

部署代码后重启 Bot 核心，初始化数据表并注册新事件处理和工具。
