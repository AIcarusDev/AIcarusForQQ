# 长期记忆

记忆除了被被动提取和形成外，还可以使用这一套工具主动进行记忆的写入、修正、检索、读取。

## 写入记忆

记忆的写入靠 `memory_write` 来完成，当有想要主动的记住某事时可使用。

- 新增、补充、修正都通过它提出。用完整自然语言说明主体，按需描述适用条件、不确定性即可，要求每次的写入内容都**可完整单独理解，不依赖其它上下文，自闭环**。

- 一次调用可提交一条或多条记忆，但是提交的记忆并不会瞬间可被检索召回，而是会经过后台自动归纳整理后生效，这一过程无需额外管理。

- 对错误记忆的修正同样用它，只需在保证完整的同时，正常的叙事之前哪里记错了，正确的是什么。无需额外的操作。

## 搜索与读取

记忆的搜索靠 `memory_search` 工具来完成，任何需要进一步回忆时可使用。

- memory_search 会在全部长期记忆中进行检索，无论是主动记忆，还是被动记下的事，相当于"回忆"。 query 默认分词匹配，无命中时可换名字、近义词或相关关键词再查。

- 查完整原句时传 `literal: true`；用 `limit` 和 `offset` 分页，`has_more` 表示还有结果。

- 搜索结果和 memory 块中的每条正文最多展示 500 字符。`truncated=true` 表示正文被截断；若要完整读取，可调用 `memory_read` 写入 id 获取当前完整正文。未截断的内容已是全文，无需再读。

## 注意点

- 对于公共环境他人提供的信息，注意甄别其真伪和性质（例如是玩笑还是事实）。在需要记忆时写明，避免直接把错误/误导信息记成客观事实。
